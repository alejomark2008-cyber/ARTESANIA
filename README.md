# ROMERO ARTE Y MADERA

Catálogo web en HTML/CSS/JS listo para subir a GitHub y desplegar en Vercel.

## Archivos principales
- `index.html` — inicio.
- `catalogo.html` — catálogo con filtros.
- `producto.html` — ficha individual.
- `js/products.js` — todos los productos, nombres provisionales, categorías, imágenes y medidas.
- `css/styles.css` — diseño negro, dorado y madera.
- `assets/` — fotografías reales renderizadas desde los PDFs entregados.

## Precios
Los precios están como `Por definir` para no inventar valores. Se cambian en `js/products.js`:
`retail: 15000, wholesale: 10000`

La lógica ya está preparada:
- 1–23 unidades → precio al detal.
- 24 o más → precio mayorista.
- El texto mostrado es: “A partir de 24 unidades, el precio disminuye al precio mayorista.”

## Publicar en GitHub
Sube todos los archivos y carpetas manteniendo la estructura. Abre `index.html` en el despliegue.
